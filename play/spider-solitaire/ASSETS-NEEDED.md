# Spider Solitaire — art assets needed

The page is **live and fully playable** with interim placeholder art that I
generated by compositing existing card assets. Everything below is a
*replacement* for something already in place, so nothing is broken while these
are outstanding — the page just doesn't look as good as the rest of the arcade.

Hand this file to Codex / imagegen.

---

## Style reference

Match the existing arcade art, not a generic card-game look.

- **Palette:** cream `#f6efe4` background, ink `#201713`, brand orange `#de6a38`,
  accent green `#1f8f77`, gold `#efb54d`. The card-table green used in-game is
  `#0b6461` with a `#2ec9b5` edge.
- **Feel:** calm, hand-painted, warm. Not glossy, not neon, not "casino".
- **Closest existing examples to match:**
  - `play/tiles/solitaire.png` and `play/tiles/freecell.png` (tile style)
  - `play/social/solitaire.png` (social card style)
  - `play/shared-assets/game-ui/pro-hand-painted/card-decks/` (the painted deck
    this game already uses at runtime)

## 1. Arcade tile — **required for visual parity**

| | |
|---|---|
| Path | `play/tiles/spider-solitaire.png` |
| Size | **144 × 144** (displayed at 72 px, so this is the 2× cut) |
| Format | PNG, ≤ 40 KB after optimisation |
| Currently | Interim: emerald card back + spade, generated with ImageMagick |

**Brief:** Should read instantly at 72 px next to 31 other tiles. The thing that
distinguishes Spider from Klondike visually is **many columns** and **eight
completed runs**. Suggest a hand-painted fan of overlapping cards in a shallow
arc with a spade motif, in the same palette as `solitaire.png` but cooler/greener
so the two are not confused in the grid.

> Do **not** simply recolour the Solitaire tile — they sit near each other in the
> grid and need to be tellable apart at a glance.

## What I do NOT need

- Card faces — the game draws these from the existing shared suit icons.
- Backgrounds/table felt — the page uses the site's cream surface.
- Win/celebration art — the shared funnel modal handles that.
- App-store art — this is a web page only; Spider Solitaire already ships inside
  Brain Games Vol 3 on Play with its own assets.

## When the art arrives

Drop the files at the paths above (same filenames), then from the repo root:

```bash
node scripts/build-webp.mjs
```

That regenerates the WebP derivatives and rewires the `<picture>` tags. Nothing
else needs touching — no HTML edits, no cache busting.
