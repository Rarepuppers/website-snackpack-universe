# Desktop icon assets

`icon-source.png` is the retained square source master. `icon.ico`, `icon.icns`, and `icon.png` are
packaging derivatives generated by `../scripts/build-icons.py` with Pillow.

The source was generated with the built-in image-generation tool on 8 August 2026, using the approved
Marine concept and character-select portrait as visual references. Production prompt:

> Create a bold, centred, front-facing Last Bastion marine helmet emblem on a deep near-black navy
> square. Preserve the original practical navy/charcoal armour, ivory side plates, amber visor, cyan
> equipment lights, restrained orange accents, and crisp modern pixel-art direction. Place it over a
> simple dark steel octagonal bastion plate. Prioritise a strong symmetrical silhouette readable at
> 16–32 px. No text, letters, numbers, watermark, weapon, skull, wings, or recognisable franchise marks.

The icon is intentionally opaque. Windows receives a multi-resolution ICO, macOS receives ICNS, and
Linux/general packaging receives a 512 px PNG.
