# Last Bastion — playtest evidence

Screenshots and captures from creator-observed local runs. Referenced by defect ID from
`presentation-defect-plan-2026-08-23.md` and by the asset briefs Codex works from.

This is documentation, not a web asset. Confirm it stays out of the sitemap, related-games, and
image-optimisation generators before committing.

## Conventions

- One folder per session: `YYYY-MM-DD-run-N/`.
- File name starts with the defect ID: `LB-04-helmet-offset-facing-east.png`.
- Add the display resolution to the name when the defect is resolution-dependent
  (`LB-09-blurry-menu-text-3840.png`).
- Never crop away the surrounding UI — the surrounding UI is the context.
- Keep the raw capture. Do not re-encode, downscale, or convert to WebP.

### 2026-09-11-screens-auto — captured, not observed

Generated by `npm run screens:last-bastion` (QA-04b). Twenty-four captures: six screens at
four viewports. **These are evidence for a human, not a verdict.** The harness asserts
nothing about appearance on purpose — a screenshot diff would freeze today's defects as the
expected result.

Read so far:

- **LB-05 closed.** "LAST BASTION" sits centred and well inside its frame at every size.
- **LB-09 closed visually.** Type is crisp at 1080p and 4K; the whole-device-pixel scaling
  is doing its job.
- **Steam Deck fills its panel.** 1280×800 is not an integer multiple of 960×540, and the
  fill path covers it with no letterbox. The August display blocker is closed.
- **LB-06 still open.** On character select the perk grid's second row sits outside the
  dossier panel, the `T0`/`T1`/`T2` entries render as bare boxes rather than tiles, and the
  perk description line collides with the first tile row.
- **New, found here:** off-screen threat arrows were clamped to the raw camera edge and
  landed on the HUD. At 960×540 the pause hint read `ESC PAU▶E`. Fixed by insetting the
  indicator band past the HUD's reserved strips; the arrows still point correctly.

Re-run the harness after any layout change rather than re-cropping these.
