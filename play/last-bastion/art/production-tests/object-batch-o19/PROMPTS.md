# Object Batch O19 prompts

Generated with the built-in image-generation tool on 2026-07-26. Each prompt requested a strict 2×2 atlas, isolated props, orthographic 3/4 top-down view, perfectly flat `#00ff00` chroma background, no text/logos/UI/characters/weapons/pickups/fire/smoke/particles/telegraphs/collision markers/gameplay values, and premium painted sci-fi materials suitable for a future Steam HD/4K source.

Families: command-center (console, tactical map table, captain chair, status board); navigation-observation (star chart, periscope, sensor mount, survey tripod); archive-records (data terminal, drawer cabinet, sample rack, memory case).

Processed with `remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill`, then restored and normalized by `normalize_object_batch_o19.py`.
