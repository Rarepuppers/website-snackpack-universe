# Storm Savant — Authorized Visual Follow-up

Production preflight for the authorized Storm Savant encounter package. The source contracts are a 4×9 body sheet, 6×1 node state strip, and 4×2 effect atlas. The normalizer trims extracted alpha per cell and centers each frame into its gameplay contract without baking rails, endpoints, timing, damage, collision, or UI.

Runtime derivatives are copied to `game-assets/`; behavior remains held behind its existing gate.
