# Character Batch C3 — Scout

Production package for Scout's released visual identity. Mechanics, presentation, audio, progression, and final
acceptance gates passed on 9 August 2026.

- [x] Full-height, text-free 1024×1536 select portrait.
- [x] Four-direction gameplay sheet: south, north, east, west columns; idle, move, and dash rows.
- [x] Transparent retained master and deterministic 96 px runtime normalization.
- [x] 128 px roster tile derived from the identity anchor.
- [x] Close-view, ordinary-combat, and 56-enemy density review.
- [x] Hero-specific damage, evade, and death audio masters plus screened OGG/MP3 derivatives.
- [x] Contextual human listening acceptance.
- [x] Armory clearance, purchase, persistence, and save/run authority tests.
- [x] Final release decision and deployment authority.

`scout-select-portrait-v1-1024x1536.png` is the identity anchor. Preserve the close tactical hood, narrow icy-cyan
visor, long side optic, slim charcoal/navy armour, cyan equipment lights, and restrained pale-sand markings.
Weapons remain runtime layers; the generated body sheet is deliberately unarmed. No separate overlay is proposed:
the hood and optic are stable body identity, and Scout currently has no modular mechanic requiring another layer.

These assets are released for ordinary Character Select and combat. Scout Clearance costs 20 Command Marks after
both Shock Doctrine and Breach Protocol (45 total); owning the clearance authorizes deployment.
