# Batch AK follow-up trio

Three large, presentation-safe support batches:

1. `gate-states-v1`: four reusable gate families with closed and open rows.
2. `debris-accents-v1`: eight compact debris/cover silhouettes.
3. `lighting-accents-v1`: eight soft, non-telegraphic lighting layers.

Each atlas is 4×2 with stable cell order preserved in the prompt record and contact sheet. Retained transparent masters and 384px-per-cell preflight derivatives remain here; runtime 256/128px derivatives are copied to `game-assets/`.

All three are candidates only. Collision, cover, safe lanes, door state, interaction, objective ownership, warnings, timers, and combat readability remain code-owned. Review at 960×540, Full HD, 4K, grayscale, colour-vision simulations, and maximum density before binding.

`normalize_batch_ak_followup_trio.py` performs deterministic alpha restoration, normalization, QA contact-sheet generation, and runtime copying.
