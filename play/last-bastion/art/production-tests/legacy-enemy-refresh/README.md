# Legacy enemy refresh

The early Scuttler, Egg Cluster, and Brain Blob sheets were regenerated as high-resolution pixel-art sources and normalized to 256px cells. The manifest binds the 256px sheets while retaining the existing logical 64px frame sizes, frame order, pivots, state counts, collision footprints, and behavior contracts.

The `*-source.png` files are retained chroma-key generation masters. The `*-alpha.png` files are intermediate cutouts. The `*-v2-256.png` files are the transparent runtime-bound derivatives for web and future Steam Full HD/4K builds.
