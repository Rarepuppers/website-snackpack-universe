# Snack Haul asset credits

Completed 2026-11-14. All geometry and audio were authored for Snack Haul. Raster masters were generated with OpenAI image generation and exported/composited for this project. No third-party models, textures, sound samples or font files were downloaded. These are project assets; this document does not declare generated work CC0.

Character designs reference the canonical SnackPack Corgi-on-the-Cob, Bark-B-Q, Belgian Waffle and Booklava images in shared-assets. Blender bundled Bfont outlines supply model lettering. Image-generation prompts, original masters, editable Blender sources and lossless audio masters are in shared-assets/art-source/snack-haul in the parent universe repository.
