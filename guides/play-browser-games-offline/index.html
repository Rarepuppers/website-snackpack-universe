How to play browser games offline

Some browser games keep working without an internet connection because their creators built in offline support. Installing a site gives it a convenient icon, but does not add that support. Here's how to prepare your games and test them before you're at 30,000 feet.

Why a website can work with no connection

The mechanism is a service worker: a small script a site can register, which the browser keeps and runs on that site's behalf — even when no tab is open. It sits between the page and the network. When you ask for a page, the service worker can answer from a copy stored on your device instead of going out to the internet.

The site has to choose which files to save. Some save files as you visit; others download an offline pack in advance. Those files use data and device storage. Follow the site's instructions, and check that the games you want are available before you disconnect.

Installing gives a supported site an icon and its own app window. Offline support can also work in a normal browser tab. Neither installation nor a service worker guarantees that every page or game has been saved.

How to install a site, per browser

  • Chrome / Edge, desktop: look for a small install icon at the right-hand end of the address bar, or open the browser menu and pick Install this site as an app (Edge) or Cast, save and share → Install page as app (Chrome).
  • Chrome, Android: menu → Add to Home screen. It will say "Install" rather than "Add" when the site supports it properly.
  • Safari, iPhone / iPad: tap the Share button, then Add to Home Screen. iOS has supported offline caching this way for a long time.
  • Other browsers: installation options vary, but a game with offline support may also work in a normal tab. Test it in the browser you plan to use.

An install option tells you how to launch a site, not whether it works offline. A site without that option can still support offline play in a tab. The reliable check is to disconnect and try the game.

The part everyone gets wrong: visit the pages first

A game can only run offline if the files it needs are saved on your device. Installing a games site does not mean its whole catalogue is ready. Some sites offer a download control; others save games after you open them.

Follow the site's instructions, then open each game you might want while you're still on wifi and let it finish loading. Switch on airplane mode, turn off any remaining network connection, and reopen and reload each game. Try a round as well: a loaded page does not prove the game itself works offline. Repeat this check before travelling, since browser storage can be cleared or evicted.

One more caveat worth knowing: anything a game fetches live — a leaderboard, a daily puzzle pulled from a server, an ad — will still fail offline even when the page itself loads. Games that keep everything on the device are the ones that survive.

Common questions

Can browser games really work with no internet?

Yes, when the site saves the files the game needs and the game does not require a live server. A service worker can provide that offline support. Installing the site alone does not add it.

How do I check before I actually need it?

Follow the site's offline instructions and open each game while online. Then disconnect fully, reopen and reload each game, and try playing a round. Repeat the test before travelling because stored files can be cleared or evicted.

Does installing a website use much storage?

It depends on the files the site saves. Images, audio and offline game packs can take substantial storage. Check your browser's site settings for usage; clearing that storage also removes saved offline files and may erase local game progress.

Is an installed site as private as an offline app?

That depends on the site, not on installing it. Installing changes how it launches, not what it does — a site that ran trackers in a tab still runs them in its own window. Check what it collects before committing either way.

Will it update, or am I stuck on an old version?

Update behaviour depends on the site. Some files are fetched from the network first; others load from a cache and update in the background. Reconnect before travelling, follow any update prompt, and test your games offline again.
