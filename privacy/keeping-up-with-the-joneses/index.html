Privacy policy

Keeping Up with the Joneses

This policy explains how Keeping Up with the Joneses handles information in its browser release. The game is local-first, requires no account, and stores your run in your own browser.

Effective date: August 30, 2026

Current release at a glance

  • No account or sign-in is required.
  • No advertising, payment, chat, contacts or location permission is used.
  • Cloudflare Web Analytics measures aggregate page visits and performance without receiving gameplay events.
  • No gameplay telemetry leaves your device in the current build, even if you allow anonymous metrics.
  • Your game state, settings and telemetry preference remain in your browser unless you export a run.

Information stored on your device

The game stores its deterministic seed, selected character and Life Plan, action log, current game state, accessibility settings, telemetry choice and a small local queue of anonymous play events in browser storage. These records provide autosave, replay, import/export, diagnostics and preference persistence. They are not synced to a SnackPack account.

Anonymous play metrics

The onboarding and Settings screen let you allow or decline anonymous play metrics. In the current local-first release, permitted events are queued on your device only and are not transmitted. The intended event fields are limited to the seed, week reached, completion state, win or loss and session timing. They do not include a name, email address, free text, advertising identifier, precise location or the contents of an exported run. This policy will be updated before any transmission is enabled.

Hosting, Web Analytics and ordinary web requests

Loading the game or this policy requires ordinary web requests. Cloudflare provides hosting, delivery, security and privacy-focused Web Analytics and may process connection information such as an IP address, browser details, referring page, request time and performance or security signals. Cloudflare's analytics beacon reports aggregate page-view and real-user performance measurements; it does not receive the game's seed, actions, finances, employment, education, events, score, save or local play-metric queue. The game does not combine Cloudflare's information with your local action log.

Exports, imports and diagnostics

Export creates a JSON backup on your device. Import reads only the file you select and reconstructs that run locally. Copy Run Diagnostic creates a redacted technical summary that excludes your identity and full save. Nothing is sent until you deliberately paste, upload or otherwise share a file or diagnostic using another service.

Downloaded Life Reports and offline cache

A Life Report share card is generated locally and downloaded to your device when you request it. The service worker may cache the game shell and manifest so the site can recover from a lost connection. You control downloaded files and browser caches through your device and browser settings.

Your choices and deletion

  • Turn anonymous play metrics on or off in Settings.
  • Start a new seeded run to replace the active local run.
  • Clear site data for keepingup.snackpackuniverse.com to remove the save, settings, local metric queue and cached shell.
  • Delete exported JSON files or Life Report images using your device’s file controls.

Audience and future features

The game is a satirical life simulation aimed at a general teen and adult audience. The current release has no multiplayer chat, account, purchase or advertising feature. If online play, accounts, leaderboards, payments, advertising or transmitted gameplay analytics are introduced, the relevant safeguards and this policy will be reviewed before release.

Security and changes

SnackPack Studios minimizes off-device data by keeping gameplay state local and uses reasonable measures to protect the sites it operates. No security method is absolute. If the game’s data handling materially changes, this page and its effective date will be updated before that change is released.
