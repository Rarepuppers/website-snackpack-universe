Last Bastion privacy policy

Last Bastion is a local-first browser game. It needs no account and keeps saves, settings and run history in your browser.

Current release at a glance

  • No account, sign-in, advertising, purchase, chat, contacts or location access is used.
  • Cloudflare Web Analytics measures aggregate page visits and performance.
  • The current release does not transmit Last Bastion gameplay-funnel events.
  • Save data, run history, settings and visit-day state remain in your browser unless you deliberately export a backup.

Information stored on your device

Last Bastion stores unlocks, settings, control bindings, run history, an expedition in progress and related save data in browser storage. It also stores local calendar-day visit state and a session ledger used by the dormant gameplay-funnel transport. If a configured transport is temporarily unavailable, a bounded session queue can retain fixed event names until a later page load. With the transport disabled, no gameplay event leaves the browser.

Hosting and website analytics

Loading the game or this policy requires ordinary web requests. Cloudflare provides hosting, delivery, security and Web Analytics and may process connection information such as an IP address, browser details, referring page, request time and performance or security signals. Cloudflare's analytics beacon reports aggregate page-view and real-user performance measurements. Last Bastion does not add its save, combat results, chosen build, seed or run history to that beacon.

Exports and links

If you export a save backup, your browser writes the file to the location you choose. SnackPack Studios does not receive that file. External links and email links leave the game and are governed by the destination service.

Your choices and deletion

  • Use the in-game reset controls to remove supported progress and settings.
  • Clear site data in your browser to remove Last Bastion browser storage and caches.
  • Delete exported save backups using your device's file controls.
  • Blocking analytics or storage must not prevent the game from running.

Future gameplay measurement

The game contains a disabled, event-capable funnel for a small closed set of coarse events such as opening the game, starting a run, reaching broad wave milestones and a coarse run outcome. It does not send free text, save data, exact scores, a player identifier or a raw wave number. This policy will be reviewed before that transport is activated, including the selected provider's configuration, retention and request data.

Contact

Questions about this policy can be sent to privacy@snackpackuniverse.com.
