# Atlas Quest promotional captures

These are authentic Atlas Quest gameplay captures, not concept art. They were
captured from the release build at SnackPack monorepo commit `3dc2276`, using the
default Globe + Physical presentation during an Easy Locate round.

- `atlas-quest-gameplay-desktop.*`: 1440 × 900, desktop layout.
- `atlas-quest-gameplay-mobile.*`: 768 × 1024, responsive compact layout.
- WebP is the preferred delivery format; PNG is the fallback and archival source.

Refresh these files when the Atlas HUD, physical terrain, or product claims
change materially. Keep promotional text in HTML rather than baking it into the
image.
